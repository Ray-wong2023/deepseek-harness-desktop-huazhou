# DeepSeek Desktop 🐋

类似 OpenAI Codex 的桌面 AI 编程助手，黑色鲸鱼 logo（DeepSeek 品牌）。v1.5 新增：任务栏/桌面/窗口图标完全一致（注入 dph_logo）、视图选项（分组+排序）、子任务折叠面板、运行状态条、项目固定存放于工作区。v1.5.1：视图选项文字按钮、工作区/顶部项目双向同步、项目归档删除常显、技能徽标。v1.5.2：修复视图菜单一直显示。v1.5.3：全部确认框换为自定义模态、删除项目同步清理顶部下拉、窗口 ready-to-show 显示聚焦。v1.5.4：工作区目录实时监控。v1.5.5：修复"＋新建项目"点击无效、无归属对话归"未分组"。v1.5.6：启动时不再把已有目录注册为项目。v1.5.7：任务栏点击切换（弹出/折叠回图标）、Claude Code 风格过程状态条（思考摘要/工具执行/生成进度实时显示在输入框上方）、✨ Skill Creator 引导式技能创建（SKILL.md 预览）、🧬 Self-Improve 自动分析会话提炼新技能/升级已有技能。

## 快速开始

1. 双击桌面的 **DeepSeek Desktop** 快捷方式（或运行 `dist\DeepSeek-Desktop-1.5.0-portable.exe`，免安装）
2. 首次启动会自动弹出设置页：填入 API Key（任意 OpenAI 兼容提供商）
3. 开始对话！支持技能与插件工具调用

## 功能模块

### 💬 对话（运行界面）
- 流式输出、多轮工具调用循环（最多 6 轮）、Markdown + 代码高亮
- ⚡ **运行界面快捷切换**：项目、模型、思考等级（off/low/medium/high/**max**）、权限徽标直接在输入框上方切换
- 🎯 **技能徽标**：输入框上方紧凑徽标显示当前技能，点击弹出技能菜单切换（或输入框输入 `/` 快选）
- 📋 **子任务折叠面板**：复杂任务模型自动输出任务清单（`- [ ]` 行），以可折叠面板展示在回复上方，可勾选完成状态
- 🏃 **运行状态条**：生成期间输入框正上方小字条实时显示状态（🧠 思考中 / 🔧 执行工具 / ✍️ 生成回复）
- 📊 **上下文实时标注**：发送按钮旁圆环 + 文字；**点击圆环弹出占用明细**（系统提示词 / 工具定义 / 对话信息 各自 tokens + 合计 + 上限百分比）
- 🧠 **思考过程可视化**：reasoning 流式显示在可折叠面板，随会话持久化
- 代码块一键运行到内置终端（▶ run）

### 📁 项目工作区
- 侧边栏"新会话"下方即工作区：**按项目文件夹分组**存放对话
- **文件夹即项目**：工作区根目录（与内置终端同一目录）下的文件夹自动成为项目；在内置终端 `mkdir` / `rmdir` 项目文件夹，工作区列表与顶部下拉**实时同步**（新建自动出现、删除自动消失，被删项目的对话归入"未分组"保留）
- **新建项目**：统一创建到工作区根目录（下拉菜单选择「＋ 新建项目…」或侧边栏 ＋ 按钮）
- **项目同步**：点击工作区里的项目分组 → 顶部项目下拉同步选中（当前项目高亮）；切换顶部下拉 → 工作区高亮同步
- **项目管理**：每个项目分组右侧常显 📦 归档（项目下所有对话归档）/ 🗑 删除（含确认）
- **视图选项**（工作区「▦ 视图选项」按钮，点击展开下拉）：分组方式 = 项目分组 / 单列表；排序方式 = 最近更新 / 手动排序（手动模式下可**拖拽**对话调整顺序）
- **对话搜索**：工作区右上方搜索框，跨项目全文搜索历史对话（标题+消息内容）
- 输入框上方"项目"下拉：切换当前项目 / 新建项目 / 选择已有项目文件夹存放新对话

### 🔐 任务权限（三级）
- 🔴 **请求批准** — 编辑外部文件和访问网络等操作始终询问，得到允许后才执行
- 🟡 **帮我批准** — 常规操作自动执行，检测到高风险行为（del/rm/format/shutdown/taskkill 等）需批准
- 🟢 **完全访问** — 不受限制地访问互联网和电脑上的所有文件
- 可在运行界面一键切换，也可在设置-配置中详细配置

### 🎨 外观（全面可定制）
- 5 套主题：深色 / 蓝白 / 浅色 / 深海蓝 / 森林绿
- **背景颜色**（自定义色值）、**强调颜色**（6 预设 + 自定义取色器）
- **UI 字体 / 代码字体**（Cascadia、Consolas、JetBrains Mono、Fira Code…）
- **UI 字号 / 代码字号**、**页面透明度**（80-100%）、**页面对比度**（85-115%）

### ⚙️ 配置
- **批准策略**（三级任务权限）、**沙盒设置**（工作区目录 + 是否限制工具读写范围）
- **推理摘要**（完整 / 摘要 200 字 / 关闭）、**输出详细程度**（简洁/标准/详细）

### 🎭 个性化
- **自定义指令** — 提供适用于此主机上所有聊天的额外说明和上下文
- **记忆** — 手动记忆库，内容注入所有对话作为长期上下文
- **个性** — 亲切 / 务实 / 专业 / 幽默 / 简洁（语气角色）

### 🎯 技能（可复用指令库）
- 内置 8 个技能 + **Claude Code 技能导入**（扫描 `~/.claude/skills`，本机 1409 个）
- **✨ Skill Creator**：引导式创建技能（名称 → 描述 → 行为指令 → SKILL.md 实时预览 → 保存到技能库）
- **🧬 Self-Improve**：一键分析最近会话，自动提炼重复工作模式 → 建议新技能 / 升级已有技能（勾选应用）
- 技能选择器支持关键字搜索，自定义技能增删改

### 🔌 插件（MCP 服务器 + 内置工具）
- 内置 5 个工具（shell/list/read/write/sysinfo，限工作区）
- MCP 插件：stdio 与 http/SSE，连接测试自动拉取工具列表
- 工具调用实时活动卡片

### 📦 归档
- 每个会话可一键**归档**（完成的任务放入归档库）
- 设置 → **已归档** 选项卡：查看、恢复、永久删除，方便回溯

### 🌐 第三方 API
- 内置 7 个预设提供商 + 自定义任意 OpenAI 兼容端点
- 每个模型独立思考等级（reasoning_effort）
- 测试连接自动拉取可用模型

## 开发

```powershell
npm install          # 安装依赖
npm start            # 开发模式运行
npm run dist         # 打包 portable exe（dist/ 目录）
```

> 打包小贴士：国内网络需设置镜像
> `$env:ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/"`
> `$env:ELECTRON_BUILDER_BINARIES_MIRROR="https://npmmirror.com/mirrors/electron-builder-binaries/"`
> 运行中的 exe 会被占用无法覆盖——升级版本号（package.json version）重新打包即可。
>
> **图标一致性**：`build/icon.ico` 必须是 **BMP(DIB) 帧** 格式（rcedit 无法处理 PNG 压缩帧的 ico，会导致注入静默失败）。若更新了桌面 dph_logo 图片，用 `powershell -File scripts/rebuild-ico.ps1` 重新生成；`scripts/afterPack.js` 会在打包时把图标注入主程序 exe，保证任务栏图标 = 桌面图标 = 窗口图标。

## 目录

```
deepseek-desktop/
├── scripts/
│   └── afterPack.js        # 打包后注入 dph_logo 图标到主程序 exe（任务栏图标一致）
├── src/
│   ├── main.js            # 主进程：窗口 / 配置 / 终端 / API 代理 / 技能 / MCP / 工具循环
│   ├── preload.js         # 安全桥接
│   └── renderer/          # UI：聊天 + 终端 + 设置（通用/外观/技能/插件）
├── build/icon.ico         # 黑色鲸鱼图标（与桌面 dph_logo 一致）
└── dist/                  # 打包产物
    └── DeepSeek-Desktop-1.5.0-portable.exe
```
